# 📚 NEXO Edu — Núcleo de Atividades Adaptadas

> **“Conectando educação, tecnologia e inclusão para transformar possibilidades em aprendizagem.”**

O **NEXO Edu** é uma plataforma educacional desenvolvida por professoras da rede pública, com o objetivo de oferecer recursos pedagógicos acessíveis, orientações práticas e ferramentas para apoiar professores na **educação inclusiva**.

---

## 🎯 Sobre o Projeto

O projeto nasceu do encontro de duas professoras da rede estadual de ensino de São Paulo que decidiram unir a vivência diária de sala de aula com a tecnologia para criar soluções reais. O foco é apoiar o planejamento pedagógico voltado a estudantes com:
* **TEA** (Transtorno do Espectro Autista)
* **SD** (Síndrome de Down)
* **AH/SD** (Altas Habilidades / Superdotação)
* **DI** (Deficiência Intelectual)
* Dificuldades de aprendizagem e recomposição básica
